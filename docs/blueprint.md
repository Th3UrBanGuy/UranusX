# **App Name**: StreamHub

## Core Features:

- Platform Listing: Allow users to input and organize streaming platform links.
- Category Separation: Categorize platforms into live TV, OTT, Sports, Cartoons, etc.
- Dashboard Display: Display platforms in a personalized dashboard format.
- Live Clock: Display a real-time clock on the dashboard.
- Calendar Integration: Integrate a calendar for date tracking within the dashboard.
- Search: Search platforms by name or category using a generative AI tool

## Style Guidelines:

- Primary color: Deep Indigo (#4B0082) to convey professionalism and sophistication.
- Background color: Very light desaturated Indigo (#F0F8FF) for a calm, unobtrusive backdrop.
- Accent color: Electric Violet (#8F00FF) to highlight interactive elements.
- Body and headline font: 'Inter' (sans-serif) for a modern and clean user interface.
- Employ a glassmorphism design for the mobile interface, creating a liquid glass Windows 12 effect with glowing glass.
- Incorporate hybrid background animations for a fully professional dashboard vibe.
- Ensure superfast, instant loading for each click, with active, alive responses.
